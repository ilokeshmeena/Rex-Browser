# Rex Browser - A Privacy-Focused Web Browser

Rex Browser is a lightweight, privacy-oriented web browser built on Google's WebView technology with built-in ad-blocking capabilities.

## Features

- **Privacy Protection**: Enhanced browsing privacy with minimal data collection
- **Built-in Ad Blocker**: Blocks intrusive ads and trackers by default
- **Lightweight**: Uses Android's WebView for efficient performance
- **Simple Interface**: Clean, distraction-free browsing experience
- **Customizable**: Options to adjust privacy and content blocking settings


## Usage

1. Launch Rex Browser
2. Browse normally - ads and trackers are blocked automatically
3. Access settings to customize your privacy preferences

## Privacy Features

- Blocks third-party trackers
- Prevents fingerprinting attempts
- No unnecessary permissions required
- Option to clear browsing data on exit
